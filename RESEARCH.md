# Windows debloating tools and needs

Research reviewed 17 November 2026. This is a survey of approaches for reviewing an existing PC, including adjacent deployment tools. The project and vendor documentation describes capabilities. It does not establish performance gains on a particular machine.

| Owner's need | Tools and evidence | Implication for an agent |
| --- | --- | --- |
| Remove unwanted inbox apps | [Win11Debloat](https://github.com/Raphire/Win11Debloat/wiki) and [O&O AppBuster](https://www.oo-software.com/en/ooappbuster) support selective app removal. | Show the package identity, who uses it, whether it is provisioned for future accounts, and how that user could recover it. A tool's default list is not owner approval. |
| Identify desktop apps, games and portable software | [BCUninstaller](https://www.bcuninstaller.com/) searches beyond conventional registrations. [WinGet](https://learn.microsoft.com/en-us/windows/package-manager/winget/uninstall) also lists software installed by other means. | Registry coverage is partial. Ask about game launchers and portable tools when relevant. Similar display names can belong to different installers. |
| Reduce sign-in delay | [Autoruns](https://learn.microsoft.com/en-us/sysinternals/downloads/autoruns/) inventories many mechanisms, including logon entries, services and shell extensions. | A Run entry establishes registration only. Ask about actual startup impact and whether the owner needs the app running immediately. |
| Recover disk space | [Storage Sense](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/manage-drive-space-with-storage-sense) addresses temporary files and configurable cleanup locations. | Start with available space and Storage categories. An installer size estimate is weak evidence. Ask about offline files, downloads and saved projects before discussing cleanup. |
| Reduce suggestions or change privacy settings | [O&O ShutUp10](https://www.oo-software.com/en/shutup10) exposes privacy controls. [Win11Debloat](https://github.com/Raphire/Win11Debloat/wiki/Default-Settings) also changes interface and policy settings. | Identify the particular suggestion, permission or feature and its account or policy scope. An installed app list alone cannot diagnose it. |
| Repeat a setup across machines | [WinUtil](https://github.com/ChrisTitusTech/winutil) combines installation, tweaks, repair and update configuration. [Winhance](https://github.com/memstechtips/Winhance) combines Windows customization and software management. | A previous machine's choices can seed questions. Recheck build, edition, hardware and owner preferences before carrying any choice forward. |
| Customize an installation image or managed fleet | [tiny11builder](https://github.com/ntdevlabs/tiny11builder) works on installation media. Microsoft documents [policy-based inbox app removal](https://learn.microsoft.com/en-us/windows/configuration/policy-based-inbox-app-removal/). | Image servicing, device policy and a signed-in user's app registration have different lifecycles. Identify the management owner and applicable edition before discussing fleet changes. |

## Audit conclusions

A useful review ties each candidate to a stated goal. For an owner who wants faster sign-in, an installed game with no evidence of startup activity is a poor candidate. For low storage, begin with a capacity baseline. For a shared PC, distinguish per-user registration, system-wide software and new-account provisioning. A review can legitimately produce zero candidates.

The collector now retains partial results, reads architecture independently of WMI, records system-drive capacity, includes exact package and desktop registration identifiers, and reads native-view Run value names independently of the WMI startup provider. Portable apps, complete autostart coverage, resource usage over time, MDM policy and recovery testing remain outside this collector. Before adding an executor, validate one narrowly scoped action through selection, identity recheck, failure, repeat run and recovery on each advertised build.
